    Limits and follow-ups

    This proves one real channel invocation through the operator-rendered split, including preparation, shared workspace access, model/MCP proxying, final result and cleanup. It does not prove native session reuse across two separate events.

    The partial clone's historical git show attempted a lazy fetch and failed because Engine had no forge credential. The agent continued and completed the task. This is a prepare/available-content limitation, not a reason to expose the Harness credential to Engine.

    Hydration reported that ach-memory was absent from the manifest, so this run did not validate memory integration.
